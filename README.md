# JM-web
***
基于jmcomic模块开发的web网页, 主要是嫌弃jmcomic的界面太丑广告太多，开发了这个网页<br>
超级现代化框架，加上无敌好用界面<br>
***
* **Django**
* **Redis**
* **Celery**
***
[安装教程](setup.md)<br>
[运行](run.md)
***
注册需要密钥，[密钥在37行](JmWebProject/JmWebProject/settings.py)<br>
允许的域名，[51,76,81行](JmWebProject/JmWebProject/settings.py)<br>
*** 
###  Feature 
+ 本地化下载
+ 登录模块（密钥注册）
+ 预览模块
